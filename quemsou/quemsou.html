Quem Somos

Este projeto foi desenvolvido com inspiração na série de jogos Final Fantasy, especialmente focado em figuras de ação e stands. O objetivo é criar uma loja virtual fictícia que oferece uma variedade de produtos relacionados a essa franquia icônica. unindo criatividade e conceitos técnicos de desenvolvimento web.

Demonstra o uso de rotas no backend com Node.js e organização hierárquica de arquivos HTML.
